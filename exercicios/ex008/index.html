Formatações de Textos

Negrito / Destaque

Contexto de uso: Use a tag B para destacar palavras-chave em um parágrafo sem indicar importância (como nomes de produtos). Use a tag STRONG para alertas, avisos graves ou termos fundamentais para a compreensão do texto.

Exemplo Isolado:

Nesta frase temos um termo em negrito usando a tag B (não semântica).

Nesta frase temos um termo em destaque usando a tag STRONG (semântica).

Diferença: A tag B apenas aplica estilização visual em negrito e não possui significado semântico. A tag STRONG indica que o conteúdo possui forte importância teórica ou prática, detendo valor semântico.

Cenário Prático Real (Painel de Autenticação):

Erro Crítico: O sistema identificou uma tentativa de acesso não autorizada.

Por favor, verifique se o seu dispositivo da marca AcessoSeguro está homologado antes de tentar novamente.

Itálico / Ênfase

Contexto de uso: Use a tag I para termos em outros idiomas, termos técnicos ou pensamentos internos. Use a tag EM quando a pronúncia ou a ênfase de uma palavra muda o sentido da frase.

Exemplo Isolado:

Nesta frase temos um termo em itálico usando a tag I (não semântica).

Nesta frase temos um termo com ênfase usando a tag EM (semântica).

Diferença: A tag I apenas altera o estilo visual para itálico e não possui significado semântico. A tag EM aplica uma ênfase verbal ou contextual ao texto, detendo valor semântico.

Cenário Prático Real (Artigo Científico / Tutorial):

Para iniciar o projeto, execute o comando no seu terminal em modo root.

Nós devemos fazer o backup dos dados hoje, caso contrário perderemos o progresso do cliente.

Nesta frase temos um texto sublinhado usando a tag U (não semântica).

Texto Riscado / Removido

Contexto de uso: Use a tag S para mostrar informações antigas que não são mais válidas (como preços antigos). Use a tag DEL para documentar a remoção de texto em sistemas de revisão de documentos ou propostas de lei editadas.

Exemplo Isolado:

Nesta frase temos um texto riscado usando a tag S (não semântica).

Nesta frase temos um texto removido usando a tag DEL (semântica).

Diferença: A tag S renderiza um risco sobre o texto para indicar que a informação já não é correta, mas não possui valor semântico estrutural. A tag DEL indica formalmente a remoção real de um conteúdo em revisões do documento, detendo valor semântico.

Cenário Prático Real (E-commerce e Revisão Contratual):

Compre o curso de: 15.000 Kz por apenas 10.000 Kz.

Cláusula 4: O contratante terá o prazo de 15 dias úteis para efetuar o pagamento da parcela.

Subscrito e Sobrescrito

Contexto de uso: Use a tag SUB para fórmulas químicas ou índices matemáticos inferiores. Use a tag SUP para potências matemáticas, ordinais ou chamadas de notas de rodapé.

Exemplo Isolado:

Fórmula da água: H2O usando a tag SUB (semântica).

Exemplo matemático: x2 usando a tag SUP (semântica).

Diferença: A tag SUB posiciona e formata o texto abaixo da linha base para fins tipográficos ou matemáticos, detendo valor semântico. A tag SUP posiciona e formata o texto acima da linha base para expoentes ou notas, detendo valor semântico.

Cenário Prático Real (Artigo Académico):

Citações

Contexto de uso: Use a tag Q para frases curtas integradas na mesma linha do parágrafo. Use a tag BLOCKQUOTE para citações em blocos independentes.

Exemplo Isolado:

Diferença: A tag Q é utilizada para citações curtas inseridas na própria linha do texto e adiciona aspas automaticamente, detendo valor semântico. A tag BLOCKQUOTE define uma secção de citação longa isolada em bloco estrutural, detendo valor semântico.

Direção de Texto e Isolamento

Contexto de uso: Use a tag BDO para forçar inversão. Use a tag BDI em dados desconhecidos do banco de dados (como nomes internacionais) para evitar falhas de orientação no layout.

Exemplo Isolado:

Exemplo invertido: HTML usando a tag BDO (não semântica)

Exemplo isolado: nome123 usando a tag BDI (semântica)

Diferença: A tag BDO substitui de forma estrita e visual a direção atual do texto de acordo com o atributo `dir`, sem valor semântico. A tag BDI isola uma parte do texto que pode ter uma direção desconhecida para evitar que ela afete bidirecionalmente os elementos adjacentes, detendo valor semântico.
